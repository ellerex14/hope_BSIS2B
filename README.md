# 🎉 Teachers’ Day Message Card

An interactive digital greeting card built with **HTML, CSS, and JavaScript** to celebrate and honor Sir Randy Bello on Teachers’ Day. This project combines heartfelt messages, an elegant navy blue and gold design, and engaging visual effects to express gratitude in a modern and creative way.

🌐 **Live Site:** [https://ellerex14.github.io/hope_BSIS2B/](https://ellerex14.github.io/hope_BSIS2B/)

## 📖 Features

🎨 **Elegant Layout** – Designed with a professional navy blue, gold, and cream color scheme.

💬 **Heartfelt Message** – Displays a special Teachers’ Day greeting for Sir Randy Bello.

✨ **Interactive Animations** – Includes glowing effects, floating particles, sparkling lights, and smooth transitions.

🌗 **Light and Dark Mode** – Switch between light and dark themes.

📱 **Responsive Design** – Designed for desktop and mobile screens.

🖼️ **Instructor’s Photo** – Features Sir Randy Bello’s portrait.

🛠️ **Technologies Used**

- **HTML5** – Structures the greeting card and its content.
- **CSS3** – Handles styling, layouts, animations, and transitions.
- **JavaScript (ES6)** – Adds interactivity, theme switching, and dynamic visual effects.

## 🚀 How to Use

1. Open the live site: 👉 [Teachers’ Day Message Card](https://ellerex14.github.io/hope_BSIS2B/)
2. Click **Open your message** to view the greeting.
3. Switch between light mode and dark mode.
4. Click **Make a wish** to enjoy the sparkling visual effects.

(Optional) Fork the repository to create your own version.

## 🎯 Customization

- Edit `index.html` to update the Teachers’ Day message or add new sections.
- Modify the CSS styles to change colors, fonts, spacing, and layout.
- Edit the JavaScript code to customize the animations, theme switcher, and interactive effects.

## 💡 Use Case

- Students greeting their teachers digitally.
- Schools sharing online Teachers’ Day appreciation cards.
- Beginners learning HTML, CSS, and JavaScript through a creative project.
